Set up a guest

        
Download and run a script in the guest to connect it to Friendzone.

        

        

        
        

          
1. Download in the guest terminal

          
          
View script

          
2. Run the downloaded script

          
sh ./friendzone-setup.sh

          
Requires Python 3. Installs the Cline plugin, adds profile hooks for bash and zsh, and prints an activation command.

        

        

          
1. Download in guest PowerShell

          
          
View script

          
2. Run the downloaded script

          
& .\friendzone-setup.ps1

          
Requires curl.exe and PowerShell 5.1 or 7. Installs the Cline plugin and saves user environment variables. Sign out/in to refresh other Windows launchers.

        

        
3. Activate and approve

        
Follow the script's activation instructions, then restart guest Cline so it inherits the new environment.

        
Return to Inbox on this host and approve the guest's join request.

        

        
What the script changes
          
The script saves the broker CA, proxy variables, loopback exclusions and fake provider keys in the guest account. When Cline is configured, it updates that guest's provider file; close Cline first so it cannot overwrite the changes, then restart it after activation.

          
Linux profile hooks are added once, with backups. Windows writes user—not machine—environment values and records previous values for rollback. Non-interactive bash inherits BASH_ENV from an activated parent; zsh reads .zshenv. Plain sh and services need an activated launcher.

          
The script does not change firewall rules or install the CA in a system trust store. It uses runtime CA variables instead. Bootstrap trusts the host/network on first download; inspect the script if unsure. Windows execution policy is not changed.

          
The Friendzone plugin adds async GitHub GraphQL tools. Requests return immediately; completion updates steer the originating Cline session. Requires a Cline build with the plugin host bridge. Restart guest Cline after setup; other plugins are preserved.

        

        
Advanced: preapprove a name
          
Normally, run setup and approve the guest's observed IP in Inbox. Preapproval allows this name from any IP before it connects; it does not configure the guest.
